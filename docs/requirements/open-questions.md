# R1 业务决定与剩余边界

> 更新日期：2026-11-21。已决定事项直接作为实现基线；未决事项与未验收环境分开记录，不再保留已解决的历史问答。

## 已冻结决定

| 主题 | 当前决定 |
|---|---|
| 登录与会话 | 用户名密码、数据库账号、Cookie Session、同源 CSRF；多 Java 实例通过 Redis 共享会话 |
| 商户准入 | 必填经营资料；平台审核；商户、首店与 Owner 同事务开通；停用保留既有履约和退款 |
| 成员与权限 | 平台角色与商户角色分离；邀请需接受；敏感写操作按当前 `userId + merchantId + permission` 复验 |
| 商品与价格 | SKU 独立状态与价格；金额使用正整数分；提交订单以 Java/MySQL 当前报价为准 |
| 图片 | 本地或显式七牛；稳定相对引用；上传重编码 PNG；不保存临时签名或 base64 |
| 库存 | 只做补货、预占、释放、出库；可售量由实时库存计算；不提供任意盘点覆盖 |
| 交易 | 单订单单商户单门店；最多 20 SKU；单 SKU 最多 99 件；15 分钟默认支付期限；模拟支付 |
| 售后 | 已支付未提货整单模拟退款；商户拒绝后可平台介入；已核销不支持本版线上退款 |
| 自提 | 高熵动态凭证、短时有效、库中存摘要、可重签、单次核销 |
| AI 导购 | 商品建议与知识回答；提案默认 10 分钟；用户显式确认后由 Java 复验并原子加购 |
| AI 流式 | 保留完整 JSON，并提供独立 SSE；取消、断线和完成以 MySQL 轮次状态为准 |
| 检索投影 | 商品使用词面召回与可选 Milvus；知识可使用本地向量或可选 Qdrant；二者均不拥有交易事实 |
| 内部知识 | Java 维护权限白名单并在返回前复验；内部原文不交给外部模型或消费者 |

# 前端设计与交互约定

本约定适用于消费者、商户和平台工作区。沿用“青柠校园”的现有视觉，以一套基础规范支撑两种布局：消费者页面移动优先，后台以桌面工作台为主，在窄屏保留同权限导航。业务行为、授权和响应字段仍以已接受规格及后端契约为准。

## 样式和设计变量

`frontend/src/styles/app.css` 是有序入口，模块必须按入口顺序加载，避免旧选择器的层叠结果变化。模块仍包含历史页面样式，新增公共规则优先归入对应基础模块，不以一次性改写所有颜色和选择器为目标。

| 模块 | 主要职责 |
| --- | --- |
| `tokens.css`、`base.css` | 品牌、文字、状态、间距、圆角和阴影变量；基础排版与焦点 |
| `consumer.css`、`guide.css` | 消费者外壳、商品和导购基础视觉，以及公共状态、弹层样式 |
| `backoffice.css` | 工作台外壳、主次按钮、表单和管理弹窗 |
| `responsive.css` | 基础动画、共享响应式布局、登录框及早期补充样式 |
| `consumer-transactions.css`、`backoffice-operations.css` | 消费者交易页面和工作台业务页面 |
| `features.css` | 图片、店铺、分页、角色导航及后续功能样式 |

新增或调整基础视觉时使用 `--color-*`、`--space-*`、`--radius-*`、`--shadow-panel` 和 `--gradient-brand`；已有 `--ink`、`--mint` 等变量暂作兼容。强调色用于主要动作，错误色用于错误和不可逆操作，文字与背景要保持可读，不能仅靠颜色区分业务状态。消费者全宽主按钮和后台主按钮使用同一品牌渐变，次要动作使用描边按钮；按所在布局保留合适尺寸。

CSS 媒体查询不能直接使用自定义属性作为断点。现有工作台在 560px 及以下使用横向导航，消费者按 400px 等现有断点适配；改动须检查 320px、390px 和桌面宽度，允许表格自身滚动，不允许整个页面意外横向溢出。

## 公共交互

| 场景 | 当前复用入口 | 约定 |
| --- | --- | --- |
| 外壳与标题 | `ConsumerShell.js`、`BackofficeShell.js` | 消费者底部导航和后台标题、侧栏分别复用；后台导航沿用原有权限过滤 |
| 按钮和表单 | `.teal-button`、`.primary-wide`、`.outline-button`、`.admin-input` | 主次操作保持明确，关联字段标签；加载或提交时禁用不安全的重复操作；键盘焦点可见 |
| 弹窗与抽屉 | `modal.js` 的 `v-modal`、`.ui-overlay` | 保留对话框可访问名称、焦点约束、Escape 关闭和焦点恢复；关闭与提交的业务限制由调用方决定 |
| 加载、空态、错误 | `StatusPanel.vue` | 明确区分加载、无数据和错误；可恢复错误提供重试；局部字段校验可继续用内联提示 |
| 分页 | `UiPagination.vue` | 调用方提供当前页、是否有下一页和加载状态，并处理前后翻页；组件不计算总页数、不发请求、不更改筛选条件 |
| 卡片和表格 | `.surface-card`、已有后台表格样式 | 页面按业务密度选择布局；列表使用稳定实体 key；行内操作必须继续遵循真实授权与最新状态 |

公共组件不承载角色权限、交易判断、幂等键或 API 规则。调用方须继续使用现有请求作用域和服务端校验，切换账号、商户或页面后不能显示旧主体响应。错误、缺货、变价、模拟支付和退款等关键事实不能被统一样式掩盖。

## 渐进范围

第一批建立样式模块、设计变量和公共分页，复用状态面板并保证静态、离线与 CSP 加载；现有页面按需继续接入。第二批按职责拆分复杂后台页面，维持商户与平台权限边界及请求竞态保护。第三批整理消费者和导购页面的一致交互，并覆盖登录、切商户、价格和库存变化、重复提交、SSE 断线及键盘操作。

新组件优先 `.vue` 和 TypeScript；旧 JS 页面可以继续工作。路由、状态管理和第三方组件库只在明确解决具体问题并完成兼容验证后再引入，不作为页面统一的前提。

## 验证

每次改动执行 [前端开发与构建入口](FRONTEND.md)中的格式、类型和生成副本检查，并按影响执行 Chromium 契约回归。`ui_design_system.py` 使用禁止真实 API 的设计预览检查三端和三个宽度，`ui_shell_bundle.py` 检查同源 CSP、离线样式加载和登录弹窗键盘行为；它们均不能代替真实 Spring/MySQL 页面验收。

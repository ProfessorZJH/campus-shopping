# 前端设计与交互约定

本约定适用于消费者、商户和平台工作区。界面采用国内主流大厂 PC Web 与 B 端 SaaS 设计变量体系，支撑多套前台零售主题、双首页首屏布局与解耦的三套后台设计系统：消费者页面移动与桌面双端适配，后台以高密度企业级桌面工作台为主并在窄屏保留同权限导航。业务行为、授权和响应字段仍以已接受规格及后端契约为准。

## 样式和设计变量

`frontend/src/styles/app.css` 是唯一有序入口，严格按以下 8 个模块顺序加载，不额外叠加覆盖补丁层或 `!important`：

| 模块             | 主要职责                                                                                                                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tokens.css`     | 大厂标准中性灰白画布与字色（`--bg-*`、`--ink-*`、`--border-*`）、默认零售主色与品牌渐变（`--color-brand`、`--gradient-brand`、`--gradient-buy`）、价格色（`--color-price`）、图表调色板（`--chart-1..6`）、语义状态色、间距、圆角、阴影与兼容别名 |
| `themes.css`     | 4 套消费端主题（`taobao`、`youpin`、`hema`、`dingdong`）、3 套独立作用域后台系统（`arco`、`antd`、`meituan`，作用于 `.application.admin-mode, .merchant-shell`）以及实时视觉方案切换面板（`DesignVariantSwitcher.js`）样式                        |
| `base.css`       | 基础重置、`:focus-visible` 3px 无障碍焦点环、`.sr-only`、公共按钮（`.teal-button`、`.primary-wide`、`.outline-button` 等）、表单输入、遮罩、全局提示、`StatusPanel.vue`、`UiPagination.vue`、图片上传与全局增强下拉框                             |
| `auth.css`       | 国内大厂纯白极简单栏登录与注册弹窗（`AuthDialog.js`）样式与键盘焦点表现                                                                                                                                                                           |
| `consumer.css`   | 消费者商城外壳、经典三栏首屏与极简高密流双首屏结构、商品详情、店铺页、购物车、结算确认、订单自提券、评价、售后与个人中心                                                                                                                          |
| `guide.css`      | AI 智能导购对话工作区、历史会话栏、知识引用卡片、推荐商品卡片与采购提案确认                                                                                                                                                                       |
| `backoffice.css` | 商户与平台工作台外壳、顶栏门店切换、经营图表、核销叫号、数据表格、商品工作区、知识库与角色权限                                                                                                                                                    |
| `responsive.css` | 跨断点（`320px`、`390px`、`560px`、`768px`、`1024px`、`1440px`）响应式布局与移动端导航切换                                                                                                                                                        |

新增或调整视觉时统一使用 `--bg-*`、`--ink-*`、`--border-*`、`--color-*`、`--space-*`、`--radius-*`、`--shadow-*` 和 `--gradient-brand`；保留 `--ink`、`--mint`、`--price` 等历史别名用于平滑兼容。界面保持约 90% 纯净浅灰白中性色画布与纯白卡片，品牌色用于主要操作与焦点态，价格色用于金额数字与关键角标，错误色用于报错与不可逆操作，文字与背景满足 WCAG AA 对比度且不单靠颜色区分业务状态。消费者全宽主按钮（`.primary-wide`）和工作台主按钮（`.teal-button`）使用同一 `--gradient-brand` 变量，次要动作使用描边或柔和按钮。

运行时主题状态由 `src/services/design-theme.js` 统一读写 URL 参数（`?ct=...&hl=...&at=...`）与本地存储（`campus_ui_theme_v7`），挂载在 `document.documentElement` 的 `data-consumer-theme`、`data-home-layout`、`data-admin-theme` 属性上；设计预览模式（`?demo=1`）自动隐藏右下角悬浮切换按钮。

CSS 媒体查询不能直接使用自定义属性作为断点。工作台在 `560px` 及以下隐藏桌面侧栏并启用横向滚动同权限导航，消费者按 `768px` / `400px` 等断点切换顶栏内联导航与底部固定导航；改动须检查 `320px`、`390px` 和桌面宽度，允许数据表格容器内部横向滚动，不允许整个页面意外横向溢出。

## 公共交互

| 场景             | 当前复用入口                                                       | 约定                                                                                                 |
| ---------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 外壳与标题       | `ConsumerShell.js`、`BackofficeShell.js`                           | 消费者底部导航和后台标题、侧栏分别复用；后台导航沿用原有权限过滤                                     |
| 视觉方案切换     | `design-theme.js`、`DesignVariantSwitcher.js`                      | 仅切换设计变量与首屏布局属性，严禁使用内联 `style` 属性，不改变任何接口或权限行为                    |
| 按钮和表单       | `.teal-button`、`.primary-wide`、`.outline-button`、`.admin-input` | 主次操作保持明确，关联字段标签；加载或提交时禁用不安全的重复操作；键盘焦点可见                       |
| 弹窗与抽屉       | `modal.js` 的 `v-modal`、`.ui-overlay`                             | 保留对话框可访问名称、焦点约束、Escape 关闭和焦点恢复；关闭与提交的业务限制由调用方决定              |
| 加载、空态、错误 | `StatusPanel.vue`                                                  | 明确区分加载、无数据和错误；可恢复错误提供重试；局部字段校验可继续用内联提示                         |
| 分页             | `UiPagination.vue`                                                 | 调用方提供当前页、是否有下一页和加载状态，并处理前后翻页；组件不计算总页数、不发请求、不更改筛选条件 |
| 卡片和表格       | `.surface-card`、已有后台表格样式                                  | 页面按业务密度选择布局；列表使用稳定实体 key；行内操作必须继续遵循真实授权与最新状态                 |

公共组件不承载角色权限、交易判断、幂等键或 API 规则。调用方须继续使用现有请求作用域和服务端校验，切换账号、商户或页面后不能显示旧主体响应。错误、缺货、变价、模拟支付和退款等关键事实不能被统一样式掩盖。

## 渐进范围

第一批建立样式模块、设计变量和公共分页，复用状态面板并保证静态、离线与 CSP 加载；现有页面按需继续接入。第二批按职责拆分复杂后台页面，维持商户与平台权限边界及请求竞态保护。第三批整理消费者和导购页面的一致交互，并覆盖登录、切商户、价格和库存变化、重复提交、SSE 断线及键盘操作。

新组件优先 `.vue` 和 TypeScript；旧 JS 页面可以继续工作。路由、状态管理和第三方组件库只在明确解决具体问题并完成兼容验证后再引入，不作为页面统一的前提。

## 验证

每次改动执行 [前端开发与构建入口](FRONTEND.md)中的格式、类型和生成副本检查，并按影响执行 Chromium 契约回归。`ui_design_system.py` 使用禁止真实 API 的设计预览检查三端和三个宽度，`ui_shell_bundle.py` 检查同源 CSP、离线样式加载和登录弹窗键盘行为；它们均不能代替真实 Spring/MySQL 页面验收。

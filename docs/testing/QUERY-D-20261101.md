## 后续审查记录：购物车 sellable 契约待定

本次源码核对确认：CartQueryCaseImpl 的 sellable 仅组合商户 ACTIVE、商品 PUBLISHED 和 SKU ACTIVE；available 独立返回，零库存仍可能 sellable=true。该行为早于 PR-C；catalog.md 的“对外可售”定义另包含 available>0，二者语义尚未统一。Cart.js 提交前另外检查 !sellable 或 available<quantity，Java 下单仍复验库存，不能将字段不一致直接等同为超卖漏洞。

本批只记录，不修改业务行为或既有接口契约。后续先确定 sellable 表示“状态有效”还是“当前有库存”，再同步文档/API说明，并覆盖零库存、余额缺失、库存不足请求量、停业/下架/失效SKU等场景。此次补充为源码审查，没有重新启动MySQL或新增业务验收结论。

后续业务整改已按用户确认选择 sellable 表示“至少可购买一件”，规则与本次独立验证见[购物车与 SKU 整改](CART-SKU-REMEDIATION-20261101.md)；上段保留本批审查时的历史结论。

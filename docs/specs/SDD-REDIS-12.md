# SDD-12 · Redis、共享会话与资源保护

日期：2026-10-31。实施基线为本地 `e5cd2c1` 加当前工作区已有的 SDD-11 改动，不能套用其他分支的类名或历史验收结果。

## 目标与范围

Redis 支撑共享 Session、入口限流、公开展示缓存、AI 请求准入和索引调度协调。MySQL 继续裁决库存、价格、经营资格、权限、订单、退款、提案确认和同会话写入。此次支持多个 Java 实例连接同一 MySQL、同一安全 Redis 和单个 Python 服务；跨主机必须共享上传存储。Python 的 SQLite 知识库和进程内执行容量不宣称已经支持多副本。

多图、SSE、多门店、真实支付和全文搜索优化不属于此次 Redis 交付。与接入相关的库存只读权限、推荐候选失效、知识库原子配额及锁定入口事务约束一并回归。

## 依赖与开关

- 保留 Java17 / Spring Boot3.4.3 / MyBatis3.0.4；Redisson 锁定版本，对接 Spring Data Redis 使用 `redisson-spring-data-34`，禁止混入其他适配模块。
- 正常启动默认启用 Redis。`REDIS_ENABLED=false` 是显式的单实例开发/隔离测试模式；运行中 Redis 故障不得自动退回内存 Session 或内存限流。
- 安全 Redis 和缓存 Redis 使用独立连接配置与独立实例。安全实例 AOF everysec / noeviction；缓存实例允许 allkeys-lru。前缀不等于内存隔离。
- 地址、随机密码、TLS、超时、namespace 只由服务端配置。测试命名空间随机且不含生产数据，禁止 FLUSHDB/FLUSHALL。

## 身份与入口契约

- 使用 Spring Session Data Redis，空闲超时 30 分钟，保留 JSESSIONID、HttpOnly、SameSite=Lax、环境要求的 Secure、登录换 ID 和 CSRF 轮换。
- 首次从内存 Session 切换会要求重新登录；Cookie 名相同不代表旧 Session 被迁移。
- 显式定义 Session 序列化并验证 SecurityContext/CSRF 的真实跨实例读取；滚动发布必须兼容同一格式。权限和账户状态继续 MySQL 实时校验。
- 登录来源、注册来源、AI 用户/全局、自提操作人/商户使用 OVERALL 共享限额。来源取直接连接地址，未经可信代理配置不信任 X-Forwarded-For。校园 NAT 需要较宽的来源阈值并配合账号维度保护。
- 超限返回 HTTP429、现有 A0007 和 Retry-After；Redis 故障返回 HTTP503、现有安全错误信封。Session 过滤器外层也要捕获依赖故障；不能仅依赖 Controller catch。

## 展示缓存契约

- 仅缓存公开商品元数据、类目和公开商户展示信息；不缓存库存、SKU 报价、权限、商户经营资格、完整页面/AI 回答。
- 商品展示路径与交易、召回读取分开。实时商品状态/版本和商户资格仍查 MySQL；缓存只存显式 JSON 投影，不序列化聚合或启用任意类型反序列化。
- 商品缓存约 30–60 秒、商户约 60–180 秒、类目约 10 分钟，含抖动。商品版本参与 Key，避免旧数据回填覆盖新版本；类目和商户提交后失效，短 TTL 限定失败时的陈旧时间。
- 事务回滚不得删缓存；提交后删除失败只记录安全诊断和指标，不把已经提交的业务写入报告成回滚。缓存不可用以短超时回退 MySQL，不重试放大数据库流量。

## AI 与任务契约

- 所有 Java→Python 调用经过共享可过期许可，非阻塞准入；许可租期大于网关最大超时，按许可 ID 释放，异常释放不能覆盖原始业务结果。
- Java 许可属于准入保护，过期/HTTP 取消不代表模型任务停止。Python 保留实际执行端的有界信号量，持有到执行真正结束；本次单 Python 服务给出实际执行上限，多 Python 副本需要另行设计执行容量。
- 同会话在 MySQL 原子领取带随机 owner token 的有限租约，远程调用期间不持有数据库事务/行锁。完成写入必须在事务中复核未过期 owner token；过期执行者不能追加消息或覆盖新执行者。失败释放只允许匹配 owner。
- 租约默认 15 分钟，覆盖当前至多三次、每次最多120秒的远程调用及 SQL 余量。崩溃后租约到期可重试，长暂停后旧执行者提交被拒绝。
- 商品同步用非阻塞 Redisson RLock + watchdog，仅协调常态执行，保留索引幂等和下一轮重试；锁不可用跳过本轮并记录诊断。锁不是 exactly-once 或外部资源 fencing。

## MySQL 迁移

新增迁移只向对话表加入租约字段，并引入知识库全局配额行（总上限1000，与现有列表契约一致）。配额领取与创建同一事务，失败不消耗配额。现有库必须先备份，维护窗口运行显式迁移；应用只核验校验和，不自动升级。全新库与重放迁移需等价。

# 校园智能导购平台：端到端交付规格 R1

> 当前实施规格，更新至 2026-10-30。R1 基线叠加 SDD 增量；接口以[当前行为契约](../api/behavior-v1.1.md)及[生成 API](../api/http-api.md)为准，实际验证见[本轮报告](../testing/DDD-DOC-CLOSURE-20261030.md)。历史规格保留阶段记录时不能覆盖当前规则。

## 范围
沿用 PRD FR-001～FR-025：身份、商户申请/审核/员工、商品多规格、库存、购物车、单商户订单、模拟支付、到店核销、未提货整单模拟退款、平台监管、知识管理及受控导购、三角色前端。真实支付、物流和已提货退货继续不在范围内。

## 本轮冻结的决定
1. 保留 Spring Boot 3.4.3、JDK17、MyBatis 和同一 MySQL；不重建官方六模块。跨域审批和交易确实需要新增 `campus-shopping-case`。
2. Spring Security 同源 Cookie 会话保留 CSRF；平台管理员只能由受控启动参数/环境变量初始化，公开注册永远不能授予平台角色。
3. 申请必填经营名称、类别、联系人、电话、首店名称、校园位置。旧教学申请缺资料时不允许审核开通；不同商户可共用申请人。
4. 审批、建商户、建首店、授予 Owner 在同一事务；重复审批返回既有结果。邀请指定已注册用户，24 小时有效，仅授予 Clerk；撤销立即生效。
5. 默认 Owner 可编辑商品，默认 Clerk 可补货/备货/核销；Owner 可配置自定义角色，商品与库存操作按实时权限复验。team.manage/store.manage/role.manage 仍为 Owner 独占，平台角色不自动成为商户 Owner。完整矩阵见 [SDD-05](SDD-RBAC-05.md)。
6. SKU 售价以整数分存储且大于零。购物车单 SKU 最多 99 件；单订单最多 20 个 SKU，必须单商户/单门店。
7. 提交订单需要客户端确认的价格及商品版本，服务端重新核价；请求键+买家+请求指纹保持幂等。下单全部预占与建单原子，未支付 15 分钟到期。
8. 付款与创建自提任务同库原子提交，不先引入异步履约消息。取消、核销、退款均锁订单行并按稳定 SKU 顺序修改库存。
9. 自提凭证由买家请求签发，使用高熵随机值，库中仅存摘要；页面丢失后可重签，旧凭证立即失效。退款处理中禁止核销。
10. 支持已付未提货整单退款；商户拒绝后买家可申请平台裁决。停用商户禁止新交易，但保留原有订单履约、退款和成员管理。
11. 知识管理支持文本/Markdown/可提取文本 PDF；不支持扫描件 OCR。资料在 Java 保存归属、生效版本和可见范围；检索引擎必须接收服务端生成的白名单，响应返回前再次复验。
12. Python AI 通过 HTTP Port 连接。无模型凭据时明确显示“本地检索演示”；商品语义召回使用可选 Milvus，知识稠密检索使用可选 Qdrant，不能混淆数据集与实际模式。未索引或依赖不可用时明确降级。见 [SDD-08](SDD-AI-HYBRID-08.md)。
13. Proposal 默认 10 分钟，用户显式确认后原子加购一次；模型不能直接创建订单、付款或修改库存。
14. 三端共用 Vue 3 单页应用，使用本地分发的 Vue 运行时；JDK17/Node22.16.0/Python3.11 参与构建，Maven 从 frontend/src 重新编译 UI。部署时由 Java 同源提供静态资源。

## 规格与验收
每项实现关联 FR 与实际测试。Java 领域模型测试、Python 检索/权限测试、浏览器交互测试和真实 Spring/MySQL 验收单独记录；替身测试、静态检查不能替代生产栈实测。不得将缺少环境/密钥标为通过。


## 本轮补充冻结与剩余边界

- 商户Owner可维护商户名称、自提门店名称及位置；平台提供独立商品监管列表和强制下架，不能借监管身份冒充Owner。
- HTTP幂等键、库存业务键、SKU规格键大小写区分；客户端生成随机键，重试时复用原键而不是重新生成。
- 请求/响应均设置真实字节上限；Java AI完整响应超时与取消覆盖响应体读取。
- Vue列表使用实体稳定key；加载期间不可触发旧数据操作，异步响应必须核对当前页面/角色/主体，退出清理私有状态。
- 单商品明确数量×单价必须满足预算；无法可靠拆分多商品数量需求时，不假装解析成功，保持明确说明。
- AI 返回完整 JSON；MySQL 对全量公开商品按需求召回最多 200 件，合并并复验可选 Milvus 语义 ID 后，SKU 均衡取样最多 300。向量索引只存 ID、文本指纹与向量，不能当作价格/库存事实库。SSE、会话删除/留存策略仍为后续能力。
- 会话/邀请列表支持 page/size 与页面翻页；单次知识白名单最多 1000 份文档，超限返回 AI0005，不静默遗漏。中文预算、模糊数量与追问继承遵循当前行为契约。
- 所有规则均须在真实MySQL/Java环境最终验证。本工作区的替身测试只验证对应层，不自动上升为产品全通过。

# UI-06：前端信息密度、角色页面与移动端导航收敛

2026-10-29 · 基于 v1.2 RBAC 候选版的**前端增量变更**。不改变业务能力范围，不新增 HTTP 路由、数据库字段或身份模型。

## 产品约束

- 页面只说明用户**做什么、结果是什么**。按钮使用具体动词；角色和知识库管理保留名称、状态、数量及必须填写的字段。
- 不在正式界面展示后端权限码、技术状态解释、测试批次、重复的操作教程、与实际业务无关的英文装饰副标题。
- **不能删除关键事实**：库存可售数量、订单/售后状态、用户权限不足、必填审核理由、文件类型/大小、自提凭证有效期、模拟支付以及失败原因必须明确。
- `?demo=1` 继续由全局“设计预览”标识，写入按钮禁用，所有写请求仍由 `previewGuard`/API 层阻止；不需要每个按钮重复标注“预览不保存”。
- 商户端与平台端在桌面使用原侧栏，`≤560px` 使用横向滚动工作台导航，进入页面时对齐当前菜单。两种布局使用**同一权限过滤来源**，不把导航显示作为服务端授权依据。
- 角色保护规则与 SDD-05 不变：OWNER/CLERK 内置不可修改，`team.manage/store.manage/role.manage` 不可被自定义角色授予，Java 独立鉴权。

## 改动位置

| 页面/组件 | 本次变更 | 保留能力 |
| --- | --- | --- |
| `RoleManager` | 隐去 `*.read/*.write` 技术码和权限教程；改为权限名称与选中数量；预览填充只读内置/自定义角色 | 角色增删改、权限依赖、成员分配、Owner 专属限制 |
| `Merchant` + `BackofficeShell` | 统一后台侧栏简洁度；删除推广装饰说明；新增移动端权限导航、自动定位当前页面 | 商品、库存、订单、知识库、角色页面和商户切换 |
| `MerchantOps` + `Platform` | 删除英文 KPI 副标题和重复权限解释；更正“库存管理”只读入口文案 | 数据统计、售后审核理由、订单/库存状态、成员管理 |
| `Knowledge` | 移除原始版本根 ID 的常驻展示；为文档操作补可访问名称 | 版本号、索引/发布状态、权限校验和上传限制 |
| `Home/Guide/Cart/Orders/ProductDetail/Account/AuthDialog/ConsumerShell` | 删去重复说明、英文装饰和不可用通知入口；统一按钮动词；品牌标题不再硬编码特定校区 | 交易状态、支付模拟说明、自提令牌时间、上传与错误提示 |

`frontend/src/` 为源码，`scripts/build-ui-bundle.py` 将 Vue 模板预编译为 `frontend/ui.bundle.js`；`scripts/install-frontend-ui.py` 将产物同步至 Spring Boot `static/`。**禁止只修改打包 JS 或静态产物而不修改源码。**

## 验收

1. RBAC 角色、权限及商户切换功能保持可用，页面不显示 `product.read` 等内部技术码；自定义角色可勾选，受保护的三项永远不可勾选。
2. 窄屏角色页面能够看到当前菜单高亮并进入商品页；仅 `stock.read` 的账号能看到库存页面，但不能看到 Owner 治理菜单或补货按钮。
3. `?demo=1#/merchant/roles` 展示示例角色和权限，修改/保存不可提交；浏览器中没有 Vue 模板错误。
4. 购物、知识库、售后、订单、AI 会话与分页回归不因文案/导航调整失效。
5. 完整 Maven、真实 Spring/MySQL 与多账号数据库隔离仍须另外执行，不能把替身浏览器测试写成真实联调结果。

# Spec Delta

## Purpose

为 Agent v1.1 提供可审查的 Java Run 和只读工具边界，使每次模型协作都绑定用户、租约、权限与资源范围，并以当前业务事实生成可验证的商品搜索回执。

## ADDED Requirements

### Requirement: Run 必须绑定身份、Scope 和有效租约

系统 SHALL 在创建 Run 时绑定用户、会话、服务端生成的 Scope、允许工具集合、幂等键和现有会话 `turn_token` 租约引用；工具执行只能使用持久化 Run 中的 Scope，并在每次调用前复核该唯一租约，不得采信模型自报角色或资源范围。

#### Scenario: 创建新的受控 Run

- **WHEN** 已登录且状态有效的用户以未使用幂等键创建 Run，并提供合法的会话租约
- **THEN** 系统创建唯一 Run，保存用户、Scope、允许工具、租约代次和过期时间，并返回不可变的 Run 摘要

#### Scenario: 重复创建请求去重

- **WHEN** 同一用户以相同幂等键重复创建 Run
- **THEN** 系统返回原 Run 摘要，不创建第二条运行记录，也不扩大原 Scope 或工具集合

#### Scenario: 租约过期后拒绝继续执行

- **WHEN** Run 的租约已过期、已取消或已进入终态
- **THEN** 系统拒绝新的工具调用并返回结构化失败，不访问商品、库存或交易写入能力

### Requirement: 工具执行必须经过白名单和参数契约

系统 SHALL 只允许已注册且被 Run 授权的只读工具；`search_products` 的输入必须符合受限 JSON 语义，未知工具、缺失字段、非法类型、未声明字段和伪造文本不得触发业务查询。

#### Scenario: 合法搜索工具调用

- **WHEN** 有效 Run 请求已注册的 `search_products`，并提供合法查询词、数量上限和明确的商户范围
- **THEN** 系统执行一次只读搜索，返回结构化候选摘要、事实校验状态和运行标识

#### Scenario: 未知工具或非法参数

- **WHEN** Run 请求未知工具、缺少必填 query、超出数量上限、携带未声明字段或传入伪造工具文本
- **THEN** 系统拒绝调用并记录安全错误类型，不执行目录、库存或任何写操作

### Requirement: 商品搜索必须由 Java 复验业务事实

系统 SHALL 将候选召回、当前价格、商品/SKU 状态、经营资格和可售库存分开读取并在返回前复验；模型、Embedding 或向量索引不得决定交易价格、库存、权限或可售结论。

#### Scenario: 返回当前可售候选

- **WHEN** 合法消费者 Scope 搜索公开商品，且候选商品、SKU、商户和实时库存均满足当前规则
- **THEN** 回执只包含当前可展示的商品/SKU 摘要、价格版本和可售数量，并标记为已由 Java 事实复验

#### Scenario: 候选与当前事实不一致

- **WHEN** 候选商品已下架、SKU 停用、商户失效、价格版本变化或库存不足
- **THEN** 系统移除或标记该候选，不把召回结果作为可交易事实返回，也不写入购物车或订单

#### Scenario: 商户范围不明确或越权

- **WHEN** 商户身份用户未明确商户范围，或请求访问其无权访问的商户私有商品
- **THEN** 系统返回澄清或拒绝结果，不读取其他商户私有数据

### Requirement: Run 状态和结果必须可重放且不产生隐式写入

系统 SHALL 以短事务保存 Run 状态和工具回执摘要；远程模型或查询过程不得持有数据库事务或行锁，重复提交已完成的同一工具调用不得重复执行，断线恢复只能读取已保存结果。

#### Scenario: 同一调用重放

- **WHEN** 同一 Run 以相同调用幂等键重复提交已完成的只读工具调用
- **THEN** 系统返回原回执，不再次访问下游工具，也不新增业务写入

#### Scenario: 模型建议加购

- **WHEN** 模型或工具参数表达加购、下单、改库存或支付意图
- **THEN** 本能力拒绝该动作并引导回既有 Proposal 确认流程，购物车、订单、库存和支付数据保持不变

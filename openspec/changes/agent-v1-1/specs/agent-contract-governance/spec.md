# Spec Delta

## Purpose

为校园商城 Agent 建立可审计的只读能力边界，使每轮请求都绑定明确的用户、身份和资源范围，并在不改变既有导购与交易契约的前提下安全处理工具选择、权限失败和兼容回退。

## ADDED Requirements

### Requirement: 首期工具必须受注册表约束

Agent SHALL 只执行已登记且声明为只读的工具；调用请求不得自行提供任意类名、URL、方法或未登记参数来扩展执行范围。

#### Scenario: 首期调用商品检索工具

- **WHEN** 模型请求已登记的 `search_products`，且参数符合公开 JSON Schema
- **THEN** 系统允许进入商品候选查询，并返回可供后续回答使用的结构化结果

#### Scenario: 模型请求未知工具

- **WHEN** 模型请求未登记的工具或声明写入购物车、订单、库存的能力
- **THEN** 系统拒绝执行，不产生业务写入，并返回可识别的安全失败结果

### Requirement: 每轮工具调用必须绑定 Scope 和身份

系统 SHALL 对每轮工具调用绑定当前用户、明确的消费者或商户身份、资源范围和授权来源；模型提供的全局角色字段不得替代服务端授权判断。

#### Scenario: 消费者读取公开商品

- **WHEN** 已登录消费者在本轮请求公开商品检索，且 Scope 允许公开商品读取
- **THEN** 系统只返回当前 Scope 内的商品候选，并保留用户与本轮关联信息

#### Scenario: 访问未授权商户资源

- **WHEN** 用户未明确指代某商户，或用户不属于被请求商户的授权范围
- **THEN** 系统拒绝私有数据读取或要求澄清，不把其他商户数据混入结果

### Requirement: 参数和资源事实必须由服务端复验

系统 SHALL 校验工具参数、资源归属和可读状态；模型、缓存、Embedding 和向量检索结果不得成为价格、库存、SKU、经营资格、权限或交易状态的最终事实。

#### Scenario: 商品候选通过事实复验

- **WHEN** 语义检索返回商品 ID，且服务端查询到当前可售 SKU、价格和库存
- **THEN** 系统只输出复验后的候选事实，并标识可供模型生成的只读结果

#### Scenario: 候选事实已失效

- **WHEN** 返回的商品已下架、库存不足、SKU 不匹配或经营资格已失效
- **THEN** 系统移除该候选或返回澄清/不可用结果，不依据过期投影继续推荐为可购买事实

### Requirement: 既有导购契约必须兼容

M0/M1 SHALL 保持现有 `/ai/chat`、SSE、Proposal 确认和交易 API 的输入输出及错误语义；Agent 验证默认关闭，不得要求旧客户端切换入口。

#### Scenario: 旧导购请求继续使用

- **WHEN** 旧客户端调用现有导购接口并使用已有会话、Proposal 或 SSE 流程
- **THEN** 系统按既有契约处理请求，Agent 验证不会改变其响应、租约或确认行为

#### Scenario: Agent 验证能力未启用

- **WHEN** 运行环境未显式启用 Agent 验证开关
- **THEN** 系统不暴露新的 Agent 用户入口，也不把请求自动路由到实验性工具执行链路

### Requirement: 推荐与业务写入必须分离

M0/M1 SHALL 将模型生成、候选召回和工具回执视为建议或查询结果；任何购物车、订单、库存或支付写入必须在未来独立产品变更中明确授权、复验和幂等后才可执行。

#### Scenario: 模型输出购买意图

- **WHEN** 模型在只读阶段生成“加入购物车”或其他交易动作建议
- **THEN** 系统不得直接修改业务数据，并按现有 Proposal 确认流程或安全提示结束本轮

#### Scenario: 未来写操作未获独立批准

- **WHEN** 调用方试图在 M0/M1 通过实验工具执行交易写入
- **THEN** 系统拒绝该调用，并保留无写入的失败证据

### Requirement: 租约和事务边界必须保持

Agent 调用 SHALL 继续使用现有 `turn_token` / `turn_expires_at` 600 秒租约；远程模型或工具长调用期间不得持有数据库事务或行锁。

#### Scenario: 租约有效且远程调用较长

- **WHEN** 当前轮次持有未过期租约并进入模型或检索调用
- **THEN** 系统允许在事务外执行远程调用，完成后在短事务内提交消息、结果或状态

#### Scenario: 租约过期或被取消

- **WHEN** 远程调用返回时租约已过期、被取消或执行代次不再匹配
- **THEN** 系统拒绝提交过期结果，不重复执行工具或产生新的业务写入

### Requirement: 失败必须可区分且不泄露敏感信息

系统 SHALL 区分参数错误、未知工具、未授权、上游超时、429、5xx、异常终止和降级回退；错误响应、日志和 Trace 不得包含凭据、完整提示词、下游异常正文或私有文档正文。

#### Scenario: 工具参数缺失

- **WHEN** 模型调用 `search_products` 缺少必填字段或字段类型不符合 Schema
- **THEN** 系统返回结构化参数失败，不执行查询，并保留可审计但已脱敏的错误信息

#### Scenario: 旧导购降级

- **WHEN** Agent 实验链路遇到明确支持的模型不兼容、超时或上游故障
- **THEN** 系统按已接受规则回退到既有 RAG/导购路径或安全失败，并记录 `DEGRADED`，不得用普通文本伪造已完成的工具调用

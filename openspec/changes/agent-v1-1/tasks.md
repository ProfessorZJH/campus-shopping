- [ ] 1.1 对照 PRD、工程实施基线、R1/SDD、ADR、HTTP/行为契约和现有 `/ai/chat`、SSE、Proposal 源码，形成 Agent v1.1 兼容矩阵；验证旧接口的请求、响应、错误、租约和确认行为没有被本变更改写。

- [ ] 1.4 建立“推荐不等于授权写入”回归用例；验证 M0/M1 不新增公开 Agent 入口、不写购物车/订单/库存/支付、不创建 `ai_run`，购买意图只能回到既有 Proposal 确认或安全提示。

## 3. M1 Python Agent Runtime POC

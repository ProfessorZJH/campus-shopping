# Tasks

本清单跟踪后续业务实施与验收，规划落盘时不预勾选；实施后只勾选有实际证据的任务，任务勾选不能代替该版本的业务验收。范围与约束见 [Proposal](proposal.md)，审查 R01～R22、依赖和技术选择见 [Design](design.md)。每次实施选择明确任务组，完成后登记对应 PR、最终提交与验证证据；任务勾选不能代替该版本的业务验收。

方案、设计、任务拆分和审查由 Codex 维护；Pi 负责后续获授权的实现，使用用户指定的 `(wuxian) deepseek-flash / max`。Pi 无法完成或偏离时由 Codex 按已有授权处理。这是编码代理的执行配置，不是平台业务的 AI 供应商选型。

每组在自身交付中同步适用测试、规格和使用说明；M6 只做整合复验。全量 Maven/Compose 走隔离 CI，本地执行相关定向检查。无真实环境的项目保留未完成或明确未验证，不能以替身或跳过冒充通过。
